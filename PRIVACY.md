# Privacy policy

attention-span is text only: output styles, skills and one slash command, written in markdown.

- **Collects nothing.** No analytics, no telemetry, no accounts.
- **Sends nothing.** No network calls, no hooks, no MCP servers, no code that runs on its own.
- **Stores nothing** of its own. The only file it ever changes is your Claude Code settings: `/style` sets or removes the `outputStyle` key in `~/.claude/settings.json` or the project's `.claude/settings.local.json`, and only when you run it.

Questions: https://github.com/alexgreensh/attention-span/issues
